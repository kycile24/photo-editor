Редактор фотографій для Windows x64. Завантажте **PhotoEditor-win-x64.zip**, розпакуйте та відкрийте **PhotoEditor.exe**. Середовище .NET входить до комплекту.

- Перетягуйте фотографії у вікно або відкривайте їх через **Ctrl+O**.
- Кадруйте, коригуйте колір, накладайте водяні знаки й порівнюйте фільтри.
- Зберігайте поточний перегляд окремою PNG-копією через **Ctrl+Shift+S**.
